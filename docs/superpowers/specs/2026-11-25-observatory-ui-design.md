# ReproLens Observatory 界面设计规格

## 目标

为科研用户与竞赛评委提供专业、现代、可实际操作的论文复现工作台。视觉不是营销页面，而是围绕“材料 → 主张 → 实验 → 证据”的高密度但易读的工作空间。现有 CLI、Fastify API、状态机、模型设置与执行器契约不变。

## 体验主张

“一座透明、安静的科研观测台：每个实验主张都有位置、状态和可追溯证据。”

## 视觉方向：Observatory

- 主背景：暖灰白 `#f4f5f3`；内容表面：`#ffffff`；侧栏：`#111c25`。
- 强调色：深海军蓝 `#17324d`，交互蓝 `#2c67e3`，成功绿 `#177e67`，警示琥珀 `#b7791f`。
- 字体：Inter / Noto Sans SC；数值与代码使用 JetBrains Mono。字体仅通过公开 CDN 引入，并提供系统回退。
- 采用统一的 Lucide 图标，不使用 emoji 或字符图标代替界面图形。
- 仅使用 4/8/12/16/20/24/32/40/48 的间距节奏；主要控件高度 40px，移动端至少 44px。
- 圆角分级：控件 8px，面板 12px，大型对话框 16px。轻边框优先，阴影仅用于浮层。
- 不使用渐变光球、玻璃拟态、装饰性网格或无意义卡片堆叠。
- 动效仅服务于页面/抽屉/状态反馈，150–240ms；`prefers-reduced-motion` 时全部禁用。

## 页面与布局

### 1. 全局导航

左侧 248px 深色工程导航，可收缩为 72px；包含品牌、工作区、工作台、复现项目、模型与算力、操作指南；底部展示服务在线状态与版本。顶部为面包屑、全局搜索/命令面板、快捷新建和主题切换。

### 2. 工作台

- 主标题：“科研工作台”；副标题明确描述任务，不写营销口号。
- 主操作：“新建复现”；次操作：“运行演示”。
- 指标条展示全部工程、进行中、已验证、总运行次数；由真实项目数据计算。
- 活跃项目采用主工作区：状态、论文标题、执行进度、claims/runs/verdict 三个数字。
- 项目列表采用分组表面与行分隔，不做每行独立悬浮卡片。
- 空状态提供实际可执行的演示和新建入口。

### 3. 项目工作区

- 标题区显示状态、名称、论文、运行环境和快捷操作。
- 复现轨道压缩为六个用户阶段：材料摄取、主张选择、计划确认、受控执行、规则核验、证据交付；映射现有 14 个状态。
- 主区域使用页签：工作流、论文与页面、运行与日志、证据与报告。
- 工作流内保持 claim 选择、plan 命令、patch diff 与审批、规则核验的完整功能。
- 右侧上下文栏：实验摘要、资源使用、证据入口、活动时间线；小屏折叠至主内容之后。
- PDF 页签提供真实页面缩略图与大图预览，不仅显示页数；补充受控页面证据访问 API。
- 运行日志使用结构化元数据与等宽 stdout/stderr 预览。

### 4. 新建复现

- 采用步骤导航：研究材料、执行环境、预算与确认。
- PDF 与仓库上传为真实上传控件，保留手动路径输入。
- 环境使用清晰的可选执行器卡片/单选组，GPU 和 CodeAgent 采用显式开关。
- 高级 SSH/平台字段根据 runner 显示。
- 右侧固定摘要展示当前选择与缺失项，提交后进入真实项目工作区。

### 5. 模型与算力

- 左侧设置导航：模型接入、执行器、CodeAgent、远程与算力平台。
- 模型预设、Base URL、模型名、密钥、超时、多模态全部保留；提供连接测试和明确反馈。
- 保存按钮仅在变更后强调；密钥留空保持原值。
- 不把密钥回显到页面或截图。

### 6. 指南与接口

保留真实 API 路由、状态机和可替换接口；使用简洁文档排版，不创建不可操作的假页面。

## 交互与可访问性

- 所有按钮、图标、输入、选择、页签、文件上传、弹层均有可见标签或 aria-label。
- 全键盘操作：跳转主内容、清晰 focus-visible、对话框焦点管理、Escape 关闭、Ctrl/Cmd+K 打开命令面板。
- 对比度达到 WCAG AA；状态不仅依靠颜色，同时显示文本。
- Toast 使用 aria-live；错误显示在对应操作附近。
- 390px 与 320px 下无水平溢出，侧栏改为移动导航，表单单列，主操作全宽。

## 验收

- 现有 42 项测试继续通过，类型检查和构建通过。
- 新增页面证据 API 测试。
- 浏览器验证真实工作流：演示 → 摄取 → claim → plan → patch → approve → PASS。
- 1440×900、1024×768、390×844、320×740 截图与溢出检查。
- 设置页、项目工作区、PDF 预览、日志和补丁审批截图。
- 检查 console error、主要操作键盘可达、减少动效模式与资源下载。
